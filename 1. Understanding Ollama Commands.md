# Ollama Commands: What I Actually Use

Okay so, after playing around with Ollama for a while, I realized there are a bunch of commands. Some I use daily. Some I barely touch. Let me walk you through what each one does, in the order you'll probably use them.

## The Commands I Use to Manage Models

Let's say you want to try out a new model. First, you need to download it.

**`ollama pull {model name}`**

This downloads the model from Ollama's server to your computer. You only need to do this once per model. It's like downloading a game before you can play it.

Example:
```bash
ollama pull deepseek-coder:1.5b
```

**`ollama list`**

Want to see what models you have sitting on your computer? This shows you everything you've downloaded. It'll also show you how much space each model takes up.

Example output:
```
NAME                     ID              SIZE    MODIFIED
deepseek-coder:1.5b     123abc          1.2 GB  2 days ago
llama3:latest            456def          4.7 GB  1 week ago
```

**`ollama show {model name}`**

Before running a model, you might want to know what it's all about. This shows you details like the model size, parameters, license, and even the default system prompt it uses.

Example:
```bash
ollama show deepseek-coder:1.5b
```

**`ollama run {model name}`**

This is the main one. This starts the model and opens up a chat session. You type your messages, hit enter, and the model replies. It's like texting with an AI.

Example:
```bash
ollama run deepseek-coder:1.5b
```

**`ollama ps`**

PS stands for "process status". This shows you which models are currently loaded in memory right now. Because you can have multiple models downloaded, but only the ones you're actively using are taking up your RAM.

Example:
```bash
ollama ps
```

**`ollama stop {model name}`**

Remember the 5-minute auto-offload thing I mentioned? Well, this is how you stop a model immediately without waiting. Use this when you're done with a model and want to free up memory right away.

Example:
```bash
ollama stop deepseek-coder:1.5b
```

**`ollama rm {model name}`**

RM stands for "remove". This deletes a model from your computer completely. Use this when you're running out of disk space or you just don't use a model anymore.

Example:
```bash
ollama rm deepseek-coder:1.5b
```

**`ollama serve`**

This manually starts the Ollama server on your machine. Normally, Ollama runs in the background automatically. You only need this if something goes wrong and the server isn't starting on its own. Most of the time, you won't touch this.

## The Commands I Use Inside a Chat Session

Okay so, you've run a model with `ollama run` and now you're inside the chat. These are the commands that work while you're talking to the AI.

**`/bye`**

This is how you exit the chat. Just type `/bye` and you're out. The model will also stop automatically after 5 minutes, but this is the clean way to leave.

**`/?`**

Forgot what commands are available? Just type `/?` and it shows you the whole list right there in the chat. Lifesaver when you're stuck.

**`/show`**

Shows you the current model's configuration – the system prompt, temperature settings, everything. Use this when you want to check what personality the model currently has.

**`/clear`**

This clears the conversation history. The model forgets everything you talked about before. It's like starting a fresh conversation without having to exit and restart the model.

**`/set`**

This is a powerful one. It changes settings for your current session. You can change things like:

- `verbose` – makes the model show its thinking process
- `quiet` – suppresses extra messages, just gives you the answer
- `history` – turns conversation memory on (default)
- `nohistory` – turns memory off, so every message is treated as a fresh conversation
- `system` – changes the model's personality right then and there

Example of changing personality:
```bash
>>> /set system "you're donald duck, but you also like to code and explain related concepts"
Set system message.
>>> what do u know about hashmaps?
*gulps* O-oh, h-hashes! Y-yes, I know a thing or two about 'em. *nervous chuckle* You
see, as Donald Duck, I'm quite familiar with the importance of... um, organizing data,
if you will.

A hashmap is like a big ol' bucket where we can store all sorts of things - *squints
eyes* people, objects, maybe even some code! *excited quack* It's a way to map keys (or
in this case, unique identifiers) to values, allowing us to look up and retrieve
information in a fast, efficient manner.

Think of it like a treasure chest, where each key unlocks a specific treasure within.
*proudly pats own hat* I've got a whole collection of hashmaps under my wing, if you
know what I mean!
```

**`/save {model name}`**

Let's say you used `/set` to change the model's personality and you really like how it behaves. You can save it as a brand new model. Then next time, you can just `ollama run your-new-model` and it'll have that personality from the start.

Example:
```bash
>>> /set system "You are a friendly teacher who explains things simply."
>>> /save my-teacher
# Now "my-teacher" is saved as a new model on your computer
```

**`/load {model name}`**

Here's something cool. You're in the middle of chatting with one model, and you realize you need a different model. You don't have to exit. Just use `/load` and switch to another model mid-conversation.

Example:
```bash
>>> /load llama3
# Now you're talking to Llama3 instead of DeepSeek
```

## Quick Reference

| When I want to... | I type... |
|------------------|-----------|
| Download a model | `ollama pull model-name` |
| See what I have downloaded | `ollama list` |
| See model details | `ollama show model-name` |
| Start chatting | `ollama run model-name` |
| See what's running | `ollama ps` |
| Stop a model now | `ollama stop model-name` |
| Delete a model forever | `ollama rm model-name` |
| Start the server manually | `ollama serve` |
| Exit the chat | `/bye` |
| See commands inside chat | `/?` |
| Show current model config | `/show` |
| Clear conversation history | `/clear` |
| Change personality or settings | `/set system "new personality"` |
| Save this as a new model | `/save new-model-name` |
| Switch to another model | `/load other-model-name` |

## A Real Workflow Example

Let me show you how I actually use these in a real session:

```bash
# I want to try DeepSeek
ollama pull deepseek-coder:1.5b

# Let me check it downloaded correctly
ollama list

# Alright, let's chat
ollama run deepseek-coder:1.5b

# Inside the chat...
>>> What is recursion?
Recursion is a fundamental concept in computer science and mathematics where a problem
is solved by breaking it down into smaller, simpler instances of the same problem. This
approach is often used in algorithms, data structures, and mathematical proofs.

Key Features:
1. **Base Case**: The simplest input that can be handled directly without further
recursion.
2. **Recursive Step**: The process of solving a problem by using the solution to a
smaller version of the same problem.

# Hmm, I want it to explain like I'm a beginner
>>> /set system You explain things like I'm 10 years old and keep it short.
>>> What is recursion?
Recursion is when a function keeps calling itself to solve smaller and smaller versions of the same problem until it reaches a stopping point.
It’s like standing between two mirrors: you keep seeing yourself again and again — but eventually the reflections stop because they get too tiny.

# Much better. I like this personality.
>>> /save my-beginner-coder

# I'm done for now
>>> /bye

# Later, I can just run my saved model
ollama run my-beginner-coder
```

That's literally everything I use. The rest of the commands exist, but these are the ones you'll actually need day to day.
