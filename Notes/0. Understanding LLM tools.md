# Understanding Local LLMs, Conda, and Ollama

Okay so, I wanted to run AI models locally on my computer. You know, like DeepSeek or Llama. No internet, no API costs, just me and the AI chatting whenever I want.

But almost immediately, I ran into my first problem.

## What is Conda and Why Do I Need It?

So here's the thing about Python. Different projects need different versions of Python and different libraries. Let's say Project A needs Python 3.9 and an old version of some library. Project B needs Python 3.12 and the latest version of that same library. If you install everything globally on your computer, they will clash. One of the projects will just break.

You might be wondering, why can't I just use pip for everything?

Well, pip only installs Python libraries. But Conda? Conda can install almost anything – Python, non-Python tools like compilers, even system-level software. It's like a manager, not just a librarian.

So Conda solves this by creating isolated "rooms" on your computer. Each room has its own Python version and its own set of packages. They don't interfere with each other. Project A lives happily in Room A. Project B lives in Room B. No fighting.

Most developers actually use both together. Conda creates the room and sets up Python. Then inside that room, they use pip to grab whatever Python packages they need. They're teammates, not rivals.

Now that I had my clean room ready, I needed something to actually run the AI model.

## Ollama: Running AI Models Without the Headache

Ollama is a tool that lets you download and run large language models on your own machine. Think of it like Docker, but for AI models. It handles all the messy technical details – GPU setup, memory management, all of it. You just tell it which model you want, and it runs.

But when I went to download DeepSeek, I saw options like "1b" and "3b" and got confused.

## What Those Numbers Actually Mean

The "b" stands for billion parameters. Parameters are basically the model's brain cells. More brain cells means smarter, but slower.

A 1b model is like a smart high school student. Fast, light, runs on pretty much any computer. But don't expect deep insights.

A 3b model is like a college graduate. Slower, needs more memory – about 4 to 6 gigabytes of RAM – but way more capable for real work like summarization, coding help, or answering questions.

So I use 1b for quick tests and experiments. I use 3b when I need actual help.

## The 5-Minute Rule That Surprised Me

Okay so here's something Ollama does automatically that I didn't expect. If you stop talking to a model for 5 minutes, it unloads itself from memory. This saves your computer's RAM. Pretty smart, right?

But what if you want to keep it loaded? Just send a message every few minutes. Or if you're done with it, manually stop it using `ollama stop {model-name}`.

## Making the Model My Own

The coolest part is that I can actually change the model's personality.

There's this file called a `Modelfile.txt` in it write something like this:
```bash
FROM deepseek-coder:1.5b 
# sets the temperature [higher is more creative, lower is more coherent]
PARAMETER temperature 0.7
# sets the context window size to 1024, this controls how many tokens the LLM can use as context to generate the next token
PARAMETER num_ctx 1024
# sets a custom system message to specify the behavior of the chat assistant
SYSTEM You are a helpful coding assistant that always explains code line by line. Be friendly and use emojis.
```

That "temperature" thing controls how creative the model is. Lower temperature means more focused and predictable. Higher temperature means more random and creative.

Then I run one command: `ollama create my-assistant -f ./Modelfile` in the integrated terminal. And just like that, I have created my own custom AI assistant with its own personality.

## How Everything Connects Together

So let me tie this all together.

Conda gives me clean, isolated rooms to work in. I create one room for my AI projects. Inside that room, I install Ollama. Ollama downloads and runs models like DeepSeek. I can customize those models using Modelfiles. And when I build something bigger – like a chatbot, or a document search tool (that's RAG), or an AI agent – I'll use LangChain to tie everything together. LangChain will talk to Ollama, and Ollama will run the model.

Conda manages the environment. Ollama runs the model. They don't compete. They work together. And the best part is everything runs locally. My data never leaves my computer. No monthly API bills. No internet required.

Just me and my AI assistant, having conversations in my own private little room that Conda built for me.
